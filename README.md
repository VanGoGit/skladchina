# Складчина 💸

Простой калькулятор общих расходов — помогает разделить траты компании и понять, кто кому должен.

Сделано для своих друзей и коллег, чтобы не считать в столбик, кто кому должен после очередной поездки или посиделок.

## Главное

- 💾 **Данные сохраняются** — ничего не пропадёт при перезагрузке страницы или закрытии браузера
- 🔗 **Приглашение по коду группы** — просто скажите друзьям код (или киньте ссылку), и они увидят те же события, участников и расходы. Регистрация не нужна

## Остальные возможности

- 👥 Группы и участники — создавайте события (поездка, вечеринка, поход) и добавляйте людей
- 🧾 Учёт расходов — кто что оплатил, с возможностью исключать участников из конкретной траты
- 🔄 Автоматический расчёт долгов — минимальное количество переводов, чтобы все были в расчёте
- 🌗 Тёмная и светлая тема
- 🌍 Русский и английский интерфейс
- 💱 Выбор валюты
- 📋 Копирование итогового списка долгов одним кликом

## Технологии

Один HTML-файл: чистый JavaScript, без фреймворков и сборки. Просто откройте `index.html` в браузере.

## Запуск

```bash
git clone <repo-url>
cd <repo-name>
open index.html
```

или откройте файл `index.html` напрямую в браузере.
